¿Qué permite esta ficha?

Esta sección permite registrar y consultar el seguimiento de una solicitud de apoyo estudiantil, manteniendo organizada la información relacionada con citas, estados y notificaciones.

Problema

Las solicitudes de apoyo pueden quedar dispersas entre diferentes canales, dificultando el seguimiento oportuno y la comunicación con el estudiante.

Solución

La plataforma centraliza el seguimiento del caso, las citas, los cambios de estado y las notificaciones, facilitando una gestión ordenada de cada solicitud.
